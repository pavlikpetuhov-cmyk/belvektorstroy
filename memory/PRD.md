# PRD: Веб-презентация строительной компании

## Дата создания: 2024-02-04

## Исходная задача
Создать красивую веб-презентацию портфолио строительной компании на основе PDF "аэропорт благовещенск" с экспортом в PDF.

## Пользовательские предпочтения
- Стиль: Современный индустриальный
- Цвета: Чёрный фон + оранжевые акценты (#FF5F1F)
- Динамичные диагональные элементы
- Акцент на масштабность проектов
- Бизнес-стиль

## Целевая аудитория
- Потенциальные заказчики строительных услуг
- Корпоративные клиенты
- Бизнес-партнёры

## Реализовано

### Слайды презентации (7 шт.)
1. **Титульный** - СтройПрофи, слоган, ключевые цифры
2. **О компании** - Компетенции, статистика (31K+ м², 15+ объектов)
3. **Аэропорт Благовещенск** - 26 000 м² перегородок КНАУФ
4. **Винный парк Крым** - Понизовка-Оползневое
5. **Декоративные панели** - 5 000 м² для Газпром Банка
6. **Винный парк Геленджик** - Образцы конструкций
7. **Контакты** - Телефон, email, кнопка PDF

### Функционал
- ✅ Scroll-snap навигация между слайдами
- ✅ Навигационные точки справа
- ✅ Клавиатурная навигация (стрелки)
- ✅ Кнопка "Наверх"
- ✅ Экспорт в PDF (html2canvas + jspdf)
- ✅ Плавающая кнопка экспорта
- ✅ Адаптивный дизайн

### Технологии
- React 19
- Tailwind CSS
- html2canvas + jspdf
- Lucide React (иконки)
- Google Fonts: Oswald + Manrope

## Ключевые файлы
- `/app/frontend/src/App.js` - Основной компонент
- `/app/frontend/src/index.css` - Стили
- `/app/design_guidelines.json` - Дизайн-система
